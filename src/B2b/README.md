# sylius/starter-b2b

Castor task to enable B2B features on Sylius (hide prices, hide checkout, customer validation): `sylius:b2b:enable`.

## Installation

In your Castor project:

```bash
castor composer require sylius/starter-b2b
```

Or install every Sylius Starter package at once with `sylius/starter`.

Read the [documentation](https://github.com/Sylius/Starter#readme) for usage.
